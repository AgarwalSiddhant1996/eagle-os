# Competitive research

## Frame the comparison
State the user job, relevant audience, products selected, comparison criteria, and observation date. Select alternatives because they solve the same job, not just because they share a category. If the user supplies a fixed comparison set, honor it.

## Gather comparable evidence
1. Use authorized direct observation when available. Record platform, version if visible, account state, plan, region when relevant, and entry conditions. Do not invent access to applications, browsing, or research tools.
2. Walk the same task for every product: entry, required inputs, choices, completion, recovery, and discoverability. Capture step counts only when the counting rule and complete path are known.
3. Cite observations with the source location and date. Label documentation as documented behavior, not hands-on verification. Label third-party reports and inferences separately.
4. Mark inaccessible or unobserved states as unknown. Do not convert an unavailable screen into evidence that a feature is absent.
5. Keep quotes short and necessary. Summarize patterns in original language; do not reproduce protected screens, text, or assets as a design deliverable.

## Synthesize
Use a task-level matrix: criterion, observed behavior, evidence, limitation, user consequence. Separate objective differences from judgments. Explain both strengths and trade-offs, including accessibility and recovery where observable.

Recommend opportunities by underlying user need, not visual imitation. For each recommendation, identify evidence, uncertainty, a feasible next validation, and why the comparison alone cannot establish demand or business impact.

## Boundaries
Use test data without real personal information. Do not scrape restricted content, bypass access controls, impersonate users, or create paid accounts without permission. Ask for approval before submissions, purchases, invitations, public posts, or other actions affecting real people. Report coverage gaps honestly rather than filling them with guesses.

## Deliverable
Provide a concise conclusion, the evidence matrix, qualified recommendations, and source links. State the observed context so the comparison can be repeated.
